# Brand: the cube, the wordmark, the voice

- **The cube.** The logo comes from Ocado's "hive" grid: an isometric cube, 2 x 2 cells per face, drawn as
  lines. Use it exactly as drawn (viewBox 0 0 200 228); never add faces, colours per cell, or a 3D render.

  <path d="M57,89 57,189 M14,114 100,164 M143,89 143,189 M100,164 186,114"/>

- **The wordmark.** `~Server Startup▮` set in JetBrains Mono, like a shell prompt with a block cursor.
- **The name.** From the Tomcat log line `Server startup in [2019] ms`: the moment a system comes up.
- **Voice.** Direct, technical, no exclamation marks, no Spanglish. Anglicisms in Spanish copy go in italics;
  product and stack names (`Cloudflare`, `WAF`, `SAP Commerce Cloud`) in code font.
- **Never name a client** other than Alcampo, Auchan, Forum Sport, Punt Roma, Job&Talent (former), and
  Inetum / Grupo Seidor as collaborations. Cloudflare is a partner, not a client.
