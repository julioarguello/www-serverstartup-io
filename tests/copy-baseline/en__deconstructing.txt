FOUR LAYERS, ON Cloudflare
layer 1 · Cloudflare
The network
How a visit reaches the Worker.
When you type the address, Cloudflare's DNS answers. The zone is signed with DNSSEC, so nobody can spoof it along the way. The connection is encrypted with TLS 1.3 at the least, and in browsers that support it not even the site's name travels in the clear. At the end of the road there is no server, only a Worker.

layer 2 · Cloudflare
The cache
What is kept at the edge, and when it is cleared.
Cloudflare's cache sits in front of the Worker: a page already stored is delivered without running anything. Only pages that ask for it are stored; everything else goes out uncached. Publishing a change in the CMS clears, by tag, that page and every page that lists it.

layer 3 · Cloudflare
Compute
Where the code that builds each page runs.
A single Cloudflare Worker builds each page on request with Astro. Files that never change, such as styles, scripts and images, are served without running it, and there is no server behind it. Before answering, the Worker adds seven security headers to every page.

Presentation
How what you see is drawn.
The interface is built with Astro and a single stylesheet: CI rejects any colour, size or spacing written anywhere else. Fonts, scripts and images come from the site itself, asking nothing of third parties. The openings pair restored photographs with a drawing animated in the browser.

Delivery
How a change reaches production.
Every change comes in as a pull request and goes through 24 steps of checks against a local copy of the site. If they all pass on main, the preview deploys itself with wrangler. Production is deployed by hand, and a guard refuses to overwrite a database that already holds content.

Quality
What is checked before anything is published.
The accessibility, design, text and language checks first plant the defect they look for and pass only once they find it, so they never pass by not looking. Lighthouse also measures performance, the text of 30 routes is frozen, and every opening is tried in Safari's and Chrome's engines. AI agents write most of the code, and the founder merges every change.
